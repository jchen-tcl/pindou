# 拼豆转换器

将喜欢的图片变成可以照着拼的图纸。

拼豆转换器是一款微信小程序，支持图片配色、单格修改、拼豆成品预览和 Excel 图纸导出。适合把卡通、插画等图片转换成带 MARD 色号和用豆量统计的制作方案。

当前代码版本：**v1.0.14** · [更新记录](CHANGELOG.md) · [项目维护备注](PROJECT_NOTES.md)

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 图片转图纸 | 提取主色、匹配色卡，减少近似杂色 |
| MARD 色卡 | 支持 221 标准版和 291 完整版，使用 A1、H7 等色号 |
| 自定义网格 | 预设 32、48、64、128、256、512；自定义每边 1～1000 格 |
| 自动裁白边 | 裁掉外围完整白色行列，保留主体内部白色，并重算用豆量 |
| 单格修改 | 使用图中已有颜色逐格改色，支持移动、缩放、高亮、撤销和重做 |
| 多种预览 | 原图、效果图、效果图加色号，以及圆形带孔豆粒的成品示意 |
| 制作统计 | 查看实际网格尺寸、每种颜色用量及总颗粒数 |
| 图片与 Excel 导出 | 保存效果图，或导出正方形格子的图纸、色号和统计表 |

## 怎么使用

1. **选择图片**：从相册选取图片，进入参数页。
2. **设置参数**：选择手头的 221／291 色卡、网格大小和最多用色数量。切换色卡时默认使用该色卡的最大色数，可以手动调低。
3. **生成图纸**：默认开启“自动裁掉四周白边”，可按需关闭。裁剪后的图纸可能是长方形。
4. **检查并微调**：进入“手动调整”，点击“放大编辑”，选色后轻点目标格子。一次只修改一格，点“完成”保存。
5. **查看和导出**：检查用豆清单；切换“拼豆成品”查看圆形豆粒效果。保存图片，或导出 Excel 照图制作。

Excel 包含三个工作表：**效果图、效果图＋色号、拼豆统计**。在“拼豆成品”视图保存图片，会保存圆形拼豆预览。

## 使用说明

- 一格对应一颗豆子。颜色数量是上限，实际用色可能更少。
- 裁白边只去掉主体范围之外的完整行列，主体范围内的背景白色仍计入用豆量。白色豆子与空格不同，空格不计数。
- 手动调整目前只开放单格改色和移动，不能新增图中原本没有的色号。修改不改变图纸宽高，也不再次裁边。
- 编辑草稿只保存在当前任务内，退出小程序后不保证恢复。撤销最多保留 20 步、合计不超过 200 万条格子变更。
- 成品预览是**熨烫前的圆形带孔豆粒摆放示意**，实际熨烫后的形状会变化。
- 成品尺寸按 5 mm 间距估算，实际以豆粒和底板为准。大网格需要更多豆子、处理时间和设备内存。
- Excel 每次导出覆盖应用内的 `effect_current.xlsx`，需要保留的版本请通过预览菜单另存。

## 本地运行

项目使用原生微信小程序 **JavaScript / WXML / WXSS / Canvas 2D**，应用运行不依赖第三方 npm 包。

1. 使用微信开发者工具导入项目目录。
2. 配置自己的小程序 AppID，或使用开发者工具支持的测试方式。
3. 点击“编译”，从首页选择图片开始使用。
4. 新增页面后若出现模板找不到，清缓存并完整编译，必要时关闭项目后重新打开。

版本号统一维护在 `utils/version.js`。开发者工具 CLI 自动化需要开启“设置 → 安全设置 → 服务端口”。

## 配色与数据来源

默认纯色优化面向卡通和插画：从稳定色块中提取主色，通过 Oklab 色差合并近似色、匹配 MARD 色卡，再清理低色差孤立杂点。小网格最多按三倍边长采样，总采样控制在一百万像素以内；不添加抖动。

合并色块会舍弃细微渐变，照片或极细线条可能丢失层次；网格更大也不代表能恢复原图没有的细节。

色卡 RGB 来自 MIT 许可的 **maxcleme/beadcolors** 开源参考数据，并非厂家官方测色。来源、原始数据和许可证见 [data/mard](data/mard/)。屏幕颜色仅供参考，221／291 应按实际购买的套装选择。

## 测试与验证

安装支持 Node.js 内置测试运行器的版本后运行：

```sh
node --test tests/*.test.js
```

测试覆盖配色、网格边界、裁白边、用量统计、单格与手势事件、撤销历史、预览缓存和 Excel 格子。部分内部测试仍覆盖已从界面移除的旧编辑工具逻辑。

安装 Python 和 Pillow 后，可比较原图在不同网格下的转换结果（同时需要 Node.js 在 PATH）：

```sh
python scripts/compare-image.py input.png output
python scripts/compare-image.py input.png output 256 512 1000
```

该脚本使用 Pillow 近似采样，不等同于微信 Canvas。`scripts/verify-editor-render.js` 可配合本地 Canvas 模块检查编辑画布，调用方式见脚本说明。

## 当前验证边界

- 本地测试和模板编译检查不替代模拟器、真机验收；原生返回手势、相册授权和最大尺寸性能仍需实机检查。
- 曾在模拟器观察到 221 色卡将蓝色配成紫色，本地相同输入未复现。可通过控制台 `[bead-plan]` 及用户目录 `bead-diagnostics.json` 对照实际配色。
